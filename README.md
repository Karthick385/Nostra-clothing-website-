# 🛍️ Nostra – E-commerce Website

## 📌 Overview

**Nostra** is a modern and responsive e-commerce website built using **HTML, CSS, and JavaScript**.
It showcases fashion products with interactive UI components like sliders, filters, and search functionality.

---

## 🚀 Features

* 🔍 **Search Functionality**

  * Live product search using JavaScript

* 🎯 **Product Filtering**

  * Filter products using checkboxes (category & color)

* 🎞️ **Hero Banner Slider**

  * Interactive image slider with navigation arrows
  * Loops back after reaching last slide

* 🛒 **Most Wanted Slider**

  * Horizontal scroll slider with left/right controls

* 🏷️ **Offer Bar**

  * Dismissible top notification bar

* 🧾 **Product Sections**

  * New Arrivals
  * Most Wanted
  * Collections

* 📱 **Responsive Design**

  * Works across different screen sizes

---

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling & Layout
* **JavaScript (Vanilla JS)** – Interactivity
* **Font Awesome** – Icons
